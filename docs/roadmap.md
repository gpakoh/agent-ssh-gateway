# Roadmap

The authoritative open engineering backlog for SSH Gateway is maintained in
[Gitea Issues](/gpakoh/agent-ssh-gateway/issues) and the
Gitea-backed coordination board (`coord_board(project="agent-ssh-gateway")`).
There is no separate repository-owned TODO checklist. Issue state is
canonical for open/closed; coordination columns express workflow status and
must not silently override Issue state.

On 2026-11-13, the 29 active items from the historical `TODO.md` were
reconciled into 23 new Issues (#875–#897) and six pre-existing Issues
(#679, #684, #801, #638, #792, #788). The migration mapping and exact
source revision are preserved in [PR #898](/gpakoh/agent-ssh-gateway/pulls/898).
Old TODO content is retained in Git history, not as an active work queue.

Implementation plans under `docs/superpowers/` are historical design/delivery
evidence, not independent authoritative backlog sources. An unchecked box in an
old plan becomes a backlog item only when current code or live evidence still
proves the gap, recorded in a Gitea Issue.
